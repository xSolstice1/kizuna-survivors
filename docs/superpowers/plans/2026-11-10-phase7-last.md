# Phase 7 — Enemy Tricks, Balance, Cleanup and Final Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three phase 6 enemies get their tricks (Clay Bird death blast, Swarm Mother split, Tool Thief steal), all 30 finished-hero configs meet the balance bar, nothing an attack does reaches past the reach box, stale PWA builds can no longer eat saves, and the whole game passes a code review and a game review.

**Architecture:** All tricks live in `crates/sim/src/world.rs`: the two death tricks hook the death drain in `remove_dead_enemies` (the one place every death passes through), the thief adds two `Enemies` columns (`carry`, `flee`) and a steal check. The client only draws the carried pickup. Reach cleanup caps radii where the sim emits them (`reach_cap`) and filters finale pushes with `in_reach`. Saves keep rejected item lines in a new `Profile` field. The service worker gains a network-first branch.

**Tech Stack:** Rust 2021, deterministic `crates/sim` (unit tests + headless balance bot), macroquad `crates/client`, plain JS service worker in `web/sw.js`, headless Chrome + Node 24 over CDP for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-07-elements-rarity-design.md`, section "Last phase (phase 7): carried from phase 6" and its subsection "Phase 7 design (2026-11-10)", which wins where they differ.

## Global Constraints

- **Implementers never commit.** The controller snapshots each task with `GIT_INDEX_FILE=<tmp> git add -A && git write-tree` and reviews tree→tree diffs. The user authorised one commit + push of the finished phase at the end. No AI attribution anywhere.
- Never commit `kizuna_save.txt` or `handoff.md`.
- Variant names are save keys (`key_of` = lowercase Debug name). Never rename an `EnemyKind`.
- Every hit on an enemy goes through `World::hurt_enemy` → `apply_hit`. Screen clears use `in_view`.
- UI: virtual 1280×720 via `kit::screen_width()/screen_height()`, `kit::MARGIN` (24) from every edge. The font lacks `⚡ ← → ×`. Elements show via `ui::element_tag` / `element_pip`, never a pill.
- Tests: build test worlds with the hero in `WorldConfig` (`play_as`). Use `bot_pick` in test loops, not `choose(0)`.
- Headless Chrome always gets `--mute-audio`.
- **Balance bar (user):** each config within 2 wins of `c1eca45` per 10-seed block (one re-run on a miss), **and** loses no more than 3 wins in total over 4 blocks (40 runs, no re-run). Configs: Ren, Riku, Shun, Toya, Kuon × 6 worlds = 30, Normal. Tune on seeds 21–60; confirm on 131, 141, 151, 161. Never tune and confirm on the same seeds.
- Trick values (spec, verbatim): Clay Bird blast radius 34, warn 1.0 s, damage 14 × enemy damage scale, hurts only the player. Swarm Mother: 3 Cursed Spawn evenly 16 units around the death point via `pending_spawns`, `MAX_ENEMIES` respected, refused spawns dropped silently, normal Cursed Spawn XP. Tool Thief: steals within its radius + 8, one at a time, any kind; flees the player 4 s, then resumes `Blink`; death drops the pickup at its death point; recycling keeps it; carrying frees the `MAX_PICKUPS` slot and never touches `next_pickup`.
- Tricks trigger on every death (weapons, screen clears, statuses, a Clay Bird's own contact hit). Hazards keep their existing rules otherwise (the Ember Leaf Set still makes the player immune to Blast).
- No new enemies, heroes, weapons or worlds. No retuning of pre-phase-6 enemies or weapons unless the balance bar forces it. Fox Mirage decoys still do not pull Leaders.
- Record every number the user changes mid-flight in the spec and this plan.

## Review Focus

1. A Tool Thief dies when the ground already holds `MAX_PICKUPS` pickups: the carried pickup must still land (it was never destroyed). Task 2 test `thief_drop_ignores_pickup_cap`.
2. A Swarm Mother dies to a screen clear (Exorcism Seal) in the same tick its spawns would land: the spawns arrive next tick and survive. Task 1 test `swarm_split_survives_screen_clear`.
3. A Clay Bird blast must not chain: other Clay Birds or any enemy inside the blast take no damage, so no blast cascade. Task 1 test `clay_bird_blast_spares_enemies`.
4. A save written by this build, loaded by this build, with an item line from a future build, must round-trip byte-identical for that line and must not shift item ids. Task 4 test `future_item_line_round_trips`.
5. A thief recycled to the spawn ring while fleeing keeps its pickup and its flee timer still counts down (it comes back). Task 2 test `recycled_thief_keeps_pickup`.

## Rulings made while writing this plan

- Ruling: the Clay Bird blast adds `pub spare_enemies: bool` to `Hazard` (false at every existing site) — spec says "same `HazardKind::Blast`" and "hurts only the player", but today's fired Blasts hurt non-boss enemies ("tags don't take sides") — cost if wrong: one field to delete and blasts that chain.
- Ruling: tricks are skipped in stress mode (`cfg.stress.is_some()`), like drops — `pending_spawns` is never drained in stress, so spawns would pile up — cost if wrong: perf scenes lack tricks.
- Ruling: a dying thief's pickup lands even past `MAX_PICKUPS` — the spec says the kill drops it and a carried pickup was never destroyed — cost if wrong: the ground can briefly hold 4 + thieves pickups.
- Ruling: a thief may steal in any `Blink` state (also faded) — the spec gives no exception — cost if wrong: an invisible thief occasionally takes a pickup.
- Ruling: GPU frame time is measured with the native client (`KZ_PERF` stress and `KZ_PERF_REAL` late-night scene, which spawns Uncommons, Elites and Leaders naturally) against a `c1eca45` build; no new perf code — cost if wrong: the stress crowd alone has no Uncommons.
- Ruling: a seal stamped on an enemy that dies early still bursts at its last position — the spec does not say; dropping it would waste the volley — cost if wrong: one branch to flip.
- Ruling: the spec's `/ecc:orch-review` is the skill's final whole-branch review; the disciplines game review runs beside it as five subagents. One fix wave covers both — cost if wrong: one extra review pass.
